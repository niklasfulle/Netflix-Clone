# Generated local profile avatars

Created with the built-in Imagegen tool. These are committed image assets;
seeding only inserts their paths and does not call an image API.

## Shared prompt

Replace `{subject}` with the corresponding subject below. Each image was
generated in its own call, with `transparent_background: false`.

```text
Use case: stylized-concept. Asset type: square profile avatar for a personal streaming app. Create ONE polished original character portrait: {subject}. Premium softly sculpted 3D illustration, tactile matte surfaces, cinematic soft studio lighting, expressive appealing silhouette, clean vibrant composition. Head and shoulders centered, face fills about 65 percent of the square, generous safe margins so it also works in a circular crop, recognizable at 48 pixels. Full bleed solid subtly graded background. No words, letters, logos, watermark, border, collage, or additional characters. Output a single square avatar image.
```

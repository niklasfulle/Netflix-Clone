### Authentication telemetry (#66)

- Added a typed allow-listed event schema with correlation IDs and one terminal
  record per attempt.
- Covered login/logout, registration, verification/resend, reset/change, MFA,
  mail delivery, profile handoff, session lifecycle, Auth.js provider failures,
  and cross-site rejection.
- Successful session polling is sampled at most once per session per 15 minutes.
- Removed account/profile identifiers and raw exception text from the profile
  handoff/polling log boundary.
- Added safe support references and operator/retention documentation.

### Authenticated public CA distribution (#67)

- Added authenticated metadata and fixed PEM/DER download endpoints.
- Added X.509, file-type, symlink, permission, size, expiry, CA, and private-key
  rejection checks with non-disclosing responses.
- Added a bilingual Settings panel with fingerprint copy/QR, expiry/rotation
  state, platform installation/removal guidance, and explicit webOS limitations.
- Ansible publishes only the public root into a read-only app mount.
- Root changes require explicit approval; the previous root is offered for a
  configurable 1–90 day overlap (30 days by default).
- Added API, unit, UI, Ansible contract, and Playwright coverage.
